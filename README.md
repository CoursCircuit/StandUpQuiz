# StandUp Quiz

Un jeu de quiz en équipes pour faire participer toute une classe. Les élèves se lèvent lorsqu’ils pensent que leur équipe possède la bonne réponse.

[Jouer dans le navigateur](https://courscircuit.github.io/StandUpQuiz/) · [Télécharger pour Mac Apple Silicon](https://github.com/CoursCircuit/StandUpQuiz/releases/download/v2.2.1/StandUpQuiz-2.2.1-arm64.dmg)

La version Mac est signée localement et non notariée ; macOS peut afficher un avertissement à l’ouverture.

## Utilisation

1. Créez une liste de paires « question ; réponse ».
2. Choisissez de 2 à 6 équipes, le nombre de questions et les règles de score.
3. Lancez la partie et projetez les propositions ; validez chaque réponse et consultez le bilan.

La bibliothèque est enregistrée dans le navigateur utilisé : exportez régulièrement vos listes. Le mode projection séparée utilise une seconde fenêtre.
